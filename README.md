# TKP Hospitality Awards 応募サポート

短い質問への回答から、自薦・他薦用の日本語応募文をブラウザー内で組み立てる静的Webアプリです。

## 特徴

- サーバー・データベース・Copilot Credits 不要
- 自薦／他薦の入力分岐
- 他薦時のみ「推薦する人」「関係」「推薦理由」を表示
- 300字カウンターと不足内容のヒント
- 応募文のコピー、TXTダウンロード、公式応募フォームへの移動
- 入力内容はブラウザーの `localStorage` にのみ保存
- PC・スマートフォン対応

## ローカルで確認

`index.html` をダブルクリックするか、次のようにローカルサーバーを起動します。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080/` を開きます。

## GitHub Pages で公開

1. このフォルダーの内容を GitHub リポジトリへ追加します。
2. GitHub の **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、対象ブランチの `/ (root)` を指定します。
4. 表示されたURLを社員へ共有します。

社外公開を避ける必要がある場合は、社内Webサーバーや SharePoint の静的ホスティング方針を確認してください。
